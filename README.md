# AI-BOT-LAB

مرکز توسعه و مدیریت پروژه‌های رباتیک و نرم‌افزاری.

## ساختار
- projects/  پروژه‌های اصلی
- templates/ قالب‌های آماده
- scripts/   اسکریپت‌های مدیریتی
- tests/     تست‌ها
- configs/   تنظیمات
- docs/      مستندات

## اصول
- هر پروژه مستقل و نسخه‌بندی‌شده
- تست قبل از انتشار
- Secrets هرگز داخل Git قرار نمی‌گیرند
- معاملات واقعی و عملیات حساس فقط با تأیید کاربر
